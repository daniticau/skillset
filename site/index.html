Small commands. Durable taste.

sks init Create the store, connect agents, import existing skills.
sks add <url> Install a skill from a tweet, a GitHub repo, or a skills.sh page.
sks always <skill> Put a rule into every agent's global instructions file, every session.
sks show <skill> Give an agent the exact canonical skill, as Markdown or JSON.
sks check Validate every skill and flag weak triggers or context bloat.
sks edit <skill> --stdin Let an agent update canonical safely, then re-mirror.
sks doctor --repair Inspect store health and reconcile mirrors.
