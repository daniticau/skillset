Small commands. Durable taste.

sks init Create the store, connect agents, import existing skills.
sks tailor Learn from session history, or capture an explicit rule.
sks list List current skills and descriptions.
sks edit <skill> Edit a canonical skill in your editor, then re-mirror.
sks doctor --repair Inspect store health and reconcile mirrors.
