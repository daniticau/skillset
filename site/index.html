skillset

Own your agent skills on disk, tailor them from past sessions, and mirror them across Codex, Claude Code, and Cursor.

npx skillset-cli init

How it works

Store

Skills live in a canonical ~/.skillset store you own.

Import

Existing agent skills are consolidated before anything is mirrored.

Tailor

sks tailor learns from past sessions and mirrors automatically.

Commands

sks initSet up the store and connect detected agents.
sks tailorMine past sessions and create useful skills.
sks listSee every current skill and short description.
sks doctor --repairReconcile mirrors if something looks off.
