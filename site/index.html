skillset
GitHub npm

One folder of skills that every coding agent reads.

Skillset keeps your SKILL.md files in one place and mirrors them into Claude Code, Codex, Kimi Code, Grok, and Cursor. Use the CLI, the Mac app, or both.

$ npm i -g skillset-cli

Then sks init. Run sks app for the Mac app. macOS, Node 20 or newer.

Every agent, one library

Add a skill once and every agent has it. Edit a copy inside any agent's folder and the edit comes back to the store.

Rules that always load

Mark a skill always-on and it goes into each agent's CLAUDE.md or AGENTS.md. The rest of the file stays yours.

Add from anywhere

A GitHub repo, a skills.sh page, a folder, or a tweet that links to a skill. Every change is a git commit, so nothing is lost.
